Politique de Confidentialité

Snake Ultra - Deluxe Edition

Cette politique de confidentialité décrit comment Snake Ultra - Deluxe Edition ("nous", "notre", "l'Application") collecte, utilise et protège vos informations lorsque vous utilisez notre application mobile.

1. Informations collectées

1.1 Données de jeu (stockées localement)

  • Progression du joueur (niveau, XP, grade)
  • Items débloqués (skins, bannières, fonds)
  • Statistiques de jeu (scores, parties jouées)
  • Préférences (paramètres audio, contrôles)

Ces données sont stockées uniquement sur votre appareil et ne sont pas transmises à nos serveurs.

1.2 Données d'authentification (optionnel)

Si vous choisissez de vous connecter avec Google ou de créer un compte :

  • Adresse email
  • Nom d'affichage
  • Photo de profil (si fournie par Google)

Ces données sont gérées par Firebase Authentication (Google) et sont utilisées uniquement pour :

  • Sauvegarder votre progression dans le cloud
  • Permettre le jeu multijoueur
  • Afficher votre profil dans les classements

1.3 Données techniques (anonymes)

  • Type d'appareil et système d'exploitation
  • Données de crash anonymisées
  • Statistiques d'utilisation agrégées

2. Utilisation des données

Nous utilisons vos données pour :

  • Fournir et améliorer l'expérience de jeu
  • Sauvegarder et synchroniser votre progression
  • Permettre les fonctionnalités multijoueur
  • Afficher des publicités pertinentes (avec votre consentement)
  • Analyser et corriger les bugs

3. Services tiers

L'Application utilise les services tiers suivants :

  • Firebase (Google) - Authentification, base de données, analytics
  • Google AdMob - Publicités (si activé)
  • Apple Game Center / Google Play Games - Classements et succès

Ces services ont leurs propres politiques de confidentialité :

  • Politique de confidentialité Google
  • Politique de confidentialité Apple

4. Publicités

L'Application peut afficher des publicités via Google AdMob. Vous pouvez :

  • Regarder des publicités récompensées (optionnel) pour obtenir des bonus
  • Voir des publicités interstitielles entre les parties

Vous pouvez refuser les publicités personnalisées lors du premier lancement ou dans les paramètres de l'application.

5. Vos droits (RGPD)

Conformément au Règlement Général sur la Protection des Données, vous avez le droit de :

  • Accéder à vos données personnelles
  • Rectifier vos informations
  • Supprimer votre compte et vos données
  • Retirer votre consentement à tout moment
  • Exporter vos données dans un format lisible

Pour exercer ces droits, contactez-nous à l'adresse ci-dessous.

6. Sécurité

Nous prenons la sécurité de vos données au sérieux :

  • Connexions chiffrées (HTTPS/TLS)
  • Authentification sécurisée via Firebase
  • Aucun stockage de mot de passe en clair
  • Accès limité aux données par notre équipe

7. Enfants

L'Application est destinée à tous les publics. Nous ne collectons pas sciemment d'informations personnelles auprès d'enfants de moins de 13 ans sans le consentement parental. Si vous êtes parent et pensez que votre enfant nous a fourni des informations personnelles, veuillez nous contacter.

8. Modifications

Nous pouvons mettre à jour cette politique de confidentialité. Les modifications seront publiées sur cette page avec une nouvelle date de mise à jour. Nous vous encourageons à consulter régulièrement cette page.
