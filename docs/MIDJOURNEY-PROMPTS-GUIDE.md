# Guide Prompts Midjourney - Snake Mobile AAA

## Style de Base (Master Prompt)

Ajoute cette base à TOUS tes prompts pour garder un style cohérent :

```
, cyberpunk neon style, dark background, glowing edges, game icon, centered, clean design, no text, vibrant neon colors on black, 4k quality --ar 1:1 --s 250 --style raw
```

**Paramètres Midjourney :**
- `--ar 1:1` : Format carré (icônes)
- `--s 250` : Stylisation moyenne-haute
- `--style raw` : Moins artistique, plus précis
- `--no text letters words` : Évite le texte parasite

## CONSEILS MIDJOURNEY

### Paramètres Recommandés
- **Icônes** : `--ar 1:1 --s 250 --style raw`
- **Backgrounds** : `--ar 16:9 --s 300 --style raw`
- **Bannières** : `--ar 3:1 --s 250 --style raw`

### Pour éviter le texte
Ajoute toujours : `no text, no letters, no words, no writing`

### Pour cohérence de style
Utilise `/prefer suffix` dans Midjourney pour ajouter automatiquement :
```
/prefer suffix , cyberpunk neon style, dark background, game icon, clean design, no text --s 250 --style raw
```

### Variations
- Utilise `V1`, `V2`, `V3`, `V4` pour des variations
- Utilise `U1`, `U2`, `U3`, `U4` pour upscale

### Post-traitement
1. Upscale en 1024x1024 minimum
2. Retire le fond avec remove.bg ou Photoshop
3. Exporte en PNG transparent ou WebP
4. Optimise la taille fichier
